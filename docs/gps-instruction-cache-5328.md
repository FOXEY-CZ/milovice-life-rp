# 5.328 — candidate instruction cache and CPU diagnostics

Independent of pending #123. One cached instruction keyed by route identity, audit identity and exact player x/y. No rounded coordinates or distance approximation; moving by any amount recomputes. Invalid or cleared route drops the cache, including cached null guidance. Caller must treat route/audit as immutable and replace them on recomputation. No timer or per-frame loop is added. Instrumentation counts computations, cache hits and elapsed instruction calculation time; these are CPU function timings, not GPU or FPS measurements. Synthetic unit tests cover repeated stationary ticks, movement, changed route/audit, invalidation and bounded retention. Next: integrate only after #123 and add a browser comparison of stationary/moving computation counts; measure actual game before claiming FPS improvements. Unit test not yet run in CI.
