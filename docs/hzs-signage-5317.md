# HZS 5.317 — označení stanice, příprava
Základ main 3f3832e65b3da54a2d5d766b02687cca3032f2e6, #111 (5.316) stále v CI. Žádné změny aktivní PR ani herního enginu.

Znovu ověřené vizuální zdroje: [DotaceEU](https://www.dotaceeu.cz/cs/evropske-fondy-v-cr/novinky/pro-hasice-a-ostatni-slozky-izs-jsme-pripravili-vi), [fotografie HZS 037](https://hzscr.gov.cz/hasicien/SCRIPT/ViewImage.aspx?docname=037.jpg&physid=1090352), [článek k otevření 11. 2. 2020](https://www.hasici.cz/zhave-aktuality/Dulezite-informace/Slavnostni-otevreni-nove-stanice-Milovice). Fotografie ukazují vodorovný červený text STANICE HZS MILOVICE na horním pásu hlavní fasády, červené číslo 112 otočené o 90 stupňů na věži a symbol telefonu, samostatný svislý červený pás s okny. Věž slouží k sušení hadic. Telefonní symbol zatím není implementován. 

Připraveny dvě vlastní bitmapové masky textu z 5×7 znaků s průhledným pozadím, bez kopírování fotopixelů. Výchozí měřítko 2, červená modelová barva. Font, tloušťka, fyzická velikost a poloha odhadnuté; žádné tvrzení o zaměření. Modul není zapojen do hry. Node test připraven, zatím nespuštěn. Další krok: ověřit geometrii a orientaci věže, případně připojit označení pouze k opt-in modelovému průčelí. Žádná nová fyzická geometrie ani kolize.
