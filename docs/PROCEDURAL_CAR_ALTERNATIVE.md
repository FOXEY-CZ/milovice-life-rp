# Original procedural road-car alternative — issue #161

Independent preparation on 5.349 main bc783f5. Existing makeRoadCar creates eight procedural variants with generated paint, geometry and independent wheel pivots. New optional batching function clones the existing model, merges only compatible opaque static sibling geometries with the same material, preserves the instanced arch trim, skips special render state and retains all four wheel pivots. Guard equal triangles and bounds; no external model data. Test compares actual isolated Chromium/Three rendering at two angles per variant, requires fewer draws and no significant visual regression, checks one wheel rotates independently without mutating the source, aborts non-local browser requests. CI pending. This is a candidate alternative to unresolved GLB provenance, not a change to default game models or approval of all project content. No physical GPU FPS or full-world performance claim. Full-world integration, lifecycle and quality comparison must precede any default changes.
