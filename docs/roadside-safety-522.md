# Milovice RP 5.22 — Roadside placement safety hotfix

**Issue:** The worldwide procedural roadside scatter placed trees and streetlights inside real mapped traffic lanes, particularly where a fixed 8.5–12 m offset from one OSM segment intersected another road, parallel carriageway, turn, or crossing.

## Fix shipped

- **Disabled worldwide random roadside furniture** generated by both `osmRoadFurniture` and the extra roadside scatter in `improveMiloviceVisuals`. It no longer emits tree trunks/crowns or streetlight poles/bulbs anywhere. No random fake roadside tree needs to be loaded merely to keep an existing smoke test passing.
- **Kept vegetation inside actual OSM park/forest polygons**; before each tree is placed, it must have a modeled horizontal clearance of at least **2.25 m radius + 1.15 m buffer** beyond every nearby carriageway, service road, or mapped footway. Unsafe trees are rejected. The source OSM way geometries are indexed in 80 m spatial cells by `scripts/road-clearance.js`, so placement is efficient across streamed neighborhoods.
- **Protected bollards** from occupying any loaded mapped traffic/pedestrian lane by checking their positions against the same road index.
- **Photo street block 5. května:** the original first-side guess overlapped OSM footway **1282187908**. A photo GPS alone cannot prove which side contains each object. The pass now checks both road sides against all loaded OSM ways and chooses the side with an unobstructed verge. The first scene's selected side is recorded in `window.__miloviceStreetEnvironment`. Plantings, fence, gate, signs and utility poles use offsets directed *outward* from that side, not into the road.
- **Retained v5.20 mobile GPU optimizations** (sharp DPR; no new PBR/shadow/render-distance costs). GLB nature assets are downloaded only when actual safe placements exist.

## What this DOES / DOES NOT establish

The test verifies **clearance against modelled OSM surfaces**, not surveyed curbs, building footprints, driveways or real-world plant ownership. All unverified map-wide generic trees and lamps are deliberately absent for now, so some streets will look sparser. Future street furniture should be restored gradually from accurately located public imagery or official asset/point data, and accepted only if it passes the same clearance contract. Do **not** turn the old random scatter generator back on as a quick visual fix.

## Diagnostics and tests

- `window.__miloviceRoadsideSafety`: number of loaded routes/segments, safe mapped green trees, rejected unsafe green trees/bollards, **randomRoadTrees=0**, **randomRoadLamps=0**.
- `window.__miloviceFurnitureBatch.disabled=true`: confirms obsolete global procedural furniture did not produce hidden meshes.
- `window.__miloviceStreetEnvironment.minRoadClearance`: minimum checked photo-street roadside clearance.
- `node scripts/road-clearance.test.mjs`: synthetic intersections, parallel streets, footpaths and actual 5. května OSM road geometry.
- Chromium smoke test verifies that unsafe global furniture is disabled while the documented photo environment still loads, walks and spawns successfully.
