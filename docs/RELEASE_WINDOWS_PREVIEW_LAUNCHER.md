# Windows local preview convenience wrapper — candidate

Double-click `Start-CROSSVEX-preview.cmd` in the repository after preparing an existing local-library stage and installing Node.js 22. Paste the stage directory (paths with spaces and surrounding quotes supported). The wrapper starts the local server with a free loopback port, opens the printed loopback URL via Windows Explorer and keeps the terminal open until stopped with Ctrl+C. If browser launch fails, copy the printed URL manually. No downloads, no registry changes, no installer, no public artifact. The wrapper validates the expected local preview paths and accepts only the exact loopback readiness line; child processes receive arguments without a command shell. Reconciled with merged #176 (5/5 PR PASS, previous main 5/5 including Pages 45896313343). Independent fixtures exercise the readiness parser, paths with spaces and startup failures; a real child server test requests the game HTML at its dynamically allocated port and stops the server. Windows and Ubuntu CI test both launcher and server. The Explorer invocation and interactive double-click are not exercised by these automated tests. CI pending. No legal approval.
