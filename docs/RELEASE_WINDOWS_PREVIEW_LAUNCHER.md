# Windows local preview convenience wrapper — candidate

Double-click `Start-CROSSVEX-preview.cmd` in the repository after preparing an existing local-library stage and installing Node.js 22. Paste the stage directory (paths with spaces and surrounding quotes supported). The wrapper starts the local server with a free loopback port, opens the printed loopback URL via Windows Explorer and keeps the terminal open until stopped with Ctrl+C. If browser launch fails, copy the printed URL manually. No downloads, no registry changes, no installer, no public artifact. The wrapper validates the expected local preview paths and accepts only the exact loopback readiness line; child processes receive arguments without a command shell. Independent fixture tests exercise the readiness parser, paths with spaces and startup failures; actual Windows CI and integration with #176 are pending. This branch is based on the previous main, does not include or modify the pending server, and must be reconciled after #176 passes. No legal approval.
