In the actual game index.html, `milovice_rp_money` (read line 2824, writes 3323/15752) and `milovice_draw_distance` (3899/3906) use localStorage. Browser storage is origin-scoped; varying the port can make existing data appear missing. Preserve a fixed 127.0.0.1 origin by default (chosen preview port 47835); optional explicit CROSSVEX_PREVIEW_PORT accepts 1024–65535 only. Never silently switch ports if occupied, never open an existing unverified server. Changing port, browser profile or machine will still change the storage context; this does not implement full saves or migration.
